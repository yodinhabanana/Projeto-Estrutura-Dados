## Descrição do projeto :page_facing_up:

<p align="justify">
  Projeto criado para teste de conhecimento e aprendizado sobre C++, uso de arquivo binário e ordenação externa.
  Tendo como objetivo ler o .CSV, e depois transformar para arquivo binário para fazer a manipulação e ordenação externa do conteúdo em ordem crescente e pelo parâmetro Value.
  O projeto está dividido em dois arquivos, o Binario.cpp que contém às funções que alterar e exibir os dados, e o ordenacao.cpp que executar a ordenação externa no arquivo binário.
  
</p>

## Como rodar a aplicação :arrow_forward:

Com um compilador, abaixe os arquivos e abra o arquivo Binario.cpp e coloque o arquivo CSV.
